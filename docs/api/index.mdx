title: MotorMetrics API
description: Access Singapore vehicle registration data, COE results, and deregistration statistics
---

The MotorMetrics API provides programmatic access to Singapore's vehicle market data, including car registrations, Certificate of Entitlement (COE) bidding results, and vehicle deregistration statistics.

## Base URL

```
https://api.motormetrics.app
```

Alternative endpoint (same data):
```
https://motormetrics.app/api/v1
```

## Authentication

The data endpoints documented here — cars, COE, and deregistrations — are public. No API key, token, or sign-up is needed:

```bash
curl https://motormetrics.app/api/v1/coe/latest
```

A small number of internal endpoints, used by MotorMetrics' own tooling, require a bearer token:

```bash
curl https://motormetrics.app/api/v1/posts \
  -H "Authorization: Bearer <token>"
```

Tokens for these endpoints are not issued publicly. A request with a missing or invalid token returns `401 Unauthorized`:

```json
{
  "error": "Unauthorised"
}
```

## Features

- **Car Registrations** - Monthly registration data by make, fuel type, and vehicle type
- **COE Results** - Historical and latest COE bidding results across all categories
- **Deregistrations** - Vehicle deregistration statistics

## Quick Start

```bash
# Get all car makes
curl https://api.motormetrics.app/cars/makes

# Get latest COE results
curl https://api.motormetrics.app/coe/latest

# Get car registrations for a specific month
curl https://api.motormetrics.app/cars?month=2025-01
```

## Response Format

All endpoints return JSON with a consistent structure:

```json
{
  "success": true,
  "data": [...],
  "meta": {
    "page": 1,
    "limit": 20,
    "total": 100,
    "totalPages": 5
  }
}
```

## Rate Limits

The API is rate limited to **60 requests per minute** per IP address. See [Rate Limiting](/api/rate-limiting) for details.

## Data Updates

Data is sourced from the Land Transport Authority (LTA) DataMall and updated monthly when new statistics are released.
